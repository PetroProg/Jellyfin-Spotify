# 🎵 Jellyfin-Spotify (Catppuccin Edition)

Персональный облачный музыкальный стриминговый сервис в стиле Spotify на базе **Jellyfin Core** с прогрессивным PWA-клиентом в палитре **Catppuccin Mocha**.

---

## ✨ Основные возможности

- 🎨 **Catppuccin Mocha UI**: минималистичный современный интерфейс без визуального шума для ПК и смартфонов (Android и iPhone iOS).
- 📲 **PWA & Auto-Update**: нативная установка на домашний экран мобильного, работа в оффлайн-режиме, автоматическое обновление при каждом релизе на сервере.
- 🎧 **Direct Stream без потерь**: прямое воспроизведение без серверного транскодирования — минимальная нагрузка на CPU (оптимизировано под Celeron N3060).
- 📥 **Импорт плейлистов Spotify**: автоматический парсинг треклиста и фоновая загрузка без подвисания системы (`nice -n 19`, 1 поток).
- 🔀 **Smart Shuffle & Рекомендации**: автоматический подбор похожих треков при окончании плейлиста или в режиме умного перемешивания.
- 🚫 **Черный список («Никогда не включать»)**: скрытие нежелательных треков с управлением и возможностью разблокировки в Настройках.
- 👥 **Мультиаккаунт (до 5 пользователей)**: открытая регистрация `/register`, раздельные плейлисты и избранное, уведомление на телефон администратора (`100.76.188.111`) при достижении 5 пользователей.
- 🔒 **Tailscale HTTPS**: защищенный доступ внутри VPN-сети по доверенному SSL-сертификату (`*.ts.net`).

---

## 🏗 Архитектура

- **Frontend**: React 18, Vite, TypeScript, Tailwind CSS, Lucide Icons, Zustand, Workbox Service Worker.
- **Backend**: Fastify (Node.js), SQLite (WAL-режим), yt-dlp, ffmpeg.
- **Медиа-сервер**: Jellyfin Core (Direct Play Only).

---

## 🚀 Быстрый запуск на сервере

```bash
cd /root/Projects/Jellyfin-Spotify

# 1. Запуск контейнеров
docker compose up -d --build

# 2. Настройка публикации через Tailscale HTTPS (порт 10443)
tailscale serve --bg --https=10443 http://127.0.0.1:5050
```

После этого приложение доступно по ссылке:
`https://petroprog.tail703e6c.ts.net:10443`

## 🔑 Настройка Spotify Developer API (Опционально)

Приложение умеет парсить плейлисты **из коробки без ключей**. Для получения расширенных рекомендаций:
1. Перейдите в [Spotify Developer Dashboard](https://developer.spotify.com/dashboard).
2. Нажмите **Create App**, укажите любое имя (например `Jellyfin-Music`).
3. Скопируйте `Client ID` и `Client Secret`.
4. Вставьте их в меню **Настройки** внутри веб-плеера.
